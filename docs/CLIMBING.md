# Climbing

Enable Climbing in Settings → Systems. All disciplines share one switch: indoor/outdoor bouldering, top rope, auto belay and lead.

1. Add a climb in Climb library, including its venue and literal grade/scale. Photos are optional PNG, JPEG or WebP files up to 5 MB, stored locally.
2. Set a project to Working on it to keep beta and next-try notes in Projects.
3. Log a session, add library climbs, record attempts, results and notes. Save draft to return later or Finish session to include it in widgets. Sessions may mix disciplines. Unknown duration stays unrecorded.
4. Edit or delete sessions in Climbing sessions. Deletion has Undo. Archive reset climbs in the library; this keeps their history.

Climbing overview uses the existing page editor. Its widgets can also be added to custom pages and shared as layouts without sharing climb records or photos. Date-range widgets exclude drafts. Grades stay grouped by discipline, environment, venue and scale; there is no conversion or overall grade score. Clean completions exclude tops reached with rests.

Complete backups and the Climbing category export include the library, sessions, projects, plans and climb photos. Format 5 accepts older FORM backups (versions 2–4) and initializes an empty climbing collection. Merge retains existing records with the same ID. Turning the system off retains all its data.

Garmin and Griptonite connections are not implemented. No health data or external account access is required.
