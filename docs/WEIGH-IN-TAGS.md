# Comparable weigh-ins

Log or edit a bodyweight measurement to add comma-separated tags. Fresh and Gym are suggested labels; any label is allowed (up to 20 per reading, 40 characters each). Tags match without case and duplicate labels are removed when saving.

Bodyweight has a tag selector for all readings, untagged readings, or one tag. It filters the chart, trailing averages, latest reading, goal distance and history. The CSV button exports the visible tag/date selection. Settings exports still contain all readings.

This selector sets the default for bodyweight widgets and the food/training context. Each weight widget can save its own filter using its selector or Configure widget. Configure widget also allows returning to the default. The Explore link preserves a widget's chosen filter. Layout sharing includes the filter label, without including measurements.

Existing measurements remain untagged. Tags and the optional default filter are additive fields in version 6 backups; no database reset is needed. Full and category JSON exports retain tags. Editing the profile's initial measurement retains its tags. Filters do not change the bodyweight snapshots already recorded in workout sets.
