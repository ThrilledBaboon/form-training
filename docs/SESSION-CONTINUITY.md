# Session reminders

The active workout now shows saved library cues and the previous comparable exercise/set notes above the set table. Partial-rep observations are labelled separately from full reps. Open previous session links directly to the original record; showing reminders does not copy or change notes.

Comparability requires the same exercise, tracking type, equipment identity, load convention and bodyweight inclusion. Repeated occurrences of one exercise match the same occurrence in the earlier workout. Only completed sets from an earlier completed session are used. Date-only imports cannot establish order within one day, so same-day entries are excluded.

Previous-performance and copy controls use this earlier comparable session. In-workout progression previews and Apply suggested targets also exclude future sessions. Library cues remain editable through the exercise library, and workout-specific notes stay independently editable for the current session.
