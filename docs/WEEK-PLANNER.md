# Combined week planner

Open Week planner in Your workspace. Each day shows separate plans and completed records for enabled systems only.

- Training: add a dated copy of a routine or a rest day. Edit or move a dated plan without changing its routine or exercise targets. Started plans are edited through the workout/history flow instead. A dated copy takes precedence over that routine’s recurring appearance on the same day.
- Climbing: add a dated session with discipline, venue and notes. Edit, move or remove it. Log this session opens a prefilled climbing log and links the completed record back to the plan, so the week does not count both.
- Food: add or edit a meal through the existing meal planner editor. Planning never deducts stock or marks a meal as eaten. Logged meals link to the food diary.

Add the Combined week planner widget to any page through Edit page. It follows the enabled systems and the current week (or its configured day), independently of a page’s historical range. Sharing a layout shares no plans or logs. Existing customized page layouts are retained; newly created/restored Overview templates include the widget.
